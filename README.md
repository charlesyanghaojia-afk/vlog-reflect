# Vlog Reflect

一个轻量的日常 Vlog 创作与反思工具包。你负责生活、拍摄和剪辑；AI 按需帮助讨论表达、整理反馈和维护方法。

**版本：0.1.1 · 模板工具包，非自动剪辑软件。** 无需安装依赖、模型或接入付费 API。

## 五分钟开始

1. 下载或 clone 本仓库。
2. 将 templates/ 里的三个文件复制到自己的私人目录，填写当前这一条即可。不要将填好的私人记录提交到公开仓库。
3. 对 AI 说：“按 AGENTS.md 协助我，只读取我指定的私人当前卡片。先直接回答我的问题，不默认写稿、预测或剪辑。”
4. 自己拍摄和剪辑；有问题时再讨论。
5. 有实际反馈后填一条 reflection.md，决定保留、修改、删除或继续观察。

## 日常只需要三张卡

| 卡片 | 用途 |
| --- | --- |
| [preferences](templates/preferences.md) | 当前真正认可的方向；保持简短 |
| [current](templates/current.md) | 正在做的一条、实际阶段、一个当前问题 |
| [reflection](templates/reflection.md) | 本次反馈、证据局限和下一步 |

卡片更新当前状态，不无限追加历史。不要求每条写脚本、用技能、预测流量或填写全部字段。

## 反思怎样变成更新

发生了什么 → 记录本人感受与观众信号 → 提出一个可尝试的变化 → 实际尝试 → 决定保留、修改、删除或待观察。

个人有效不等于普遍有效。只将适合公开复用的方法、去敏示例或工具改进提交到本仓库。维护规则见 [CONTRIBUTING.md](CONTRIBUTING.md)，版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 可选工具

- 普通讨论：任意支持文件上下文的 AI 助手即可。
- 文案与结构：按任务选择写作工具，不必叠加多个完整流程。
- 保存：本地 Markdown 即可；也可自行选择 Google Docs / Sheets，连接和权限另行配置。
- 复盘：用户提供数据或授权访问平台后台；注明平台、版本、采集时间和统计窗口。
- GitHub：保存通用工具和版本；私人作品数据另存。

第三方 skills 不随本包分发，也不是必需依赖。跨电脑使用时分别记录技能版本与核验日期，仓库中的文件不等于该电脑已经安装；升级前备份，升级后检查完整目录与引用。没有自动抓取、定时任务、音频转写、剪辑或发布功能；数据分析不保证播放量提升。

## 公开内容边界

不提交原素材、私人文案、账号数据、私人文档链接、个人文件路径、凭据或第三方视频。示例均为虚构。公开仓库中的提交历史也会保留已提交内容，不能仅靠之后删除文件保护隐私。
